# 四维围棋设计

棋盘是有限格点集合 {0,…,n−1}⁴，坐标顺序为 (x,y,z,w)。仅一个坐标相差 1 的点相邻，不循环、不含对角线。内点最多 8 个邻点；边界自然减少。通过此邻接关系定义同色连通块、不同空点构成的气、无气提子。落子先提敌方棋块，再检测自己的气，禁自杀；任何重现已有棋盘的落子禁止（位置超级劫），停着豁免。

默认 3⁴=81 点，可选 4⁴、5⁴；黑先，默认白贴 0.5，可自定义。此贴目只是小游戏参数，未宣称公平。双方连续停着进入数子；使用四维图上的面积计分：活子加仅接触本方的空连通区域，混合边界或无边界为公气。玩家可以按棋块标记死子并重算，电脑不自动裁定死活。认输直接结束。

Python 3.10+ 标准库负责规则、启发式电脑、HTTP 接口、合法性和存档验证。浏览器负责 SVG 切片矩阵；列固定 z、行固定 w，切片内显示 x/y。可交换显示轴，悬停/键盘聚焦显示 8 邻点、整块棋子与全部气，避免把切片当成独立棋盘。Python 是唯一棋局事实源。

HTTP 只绑定 127.0.0.1；写请求核对 Origin、Host、JSON 内容类型、长度与版本号。同一浏览器共享一个本地棋局；模式 local/ai，电脑执白。功能限于落子、停着、认输、悔棋、提示、存取 JSON、教学局面与终局死子标记。电脑是有预算的启发式对手，不称为强棋 AI。

验收：规则测试覆盖全部四轴、跨层提子、自杀、提子后的合法落子、同形禁着、悔棋和存档；HTTP 真实请求测试覆盖修改、回读、校验与电脑；真实浏览器走教学提子、悔棋、保存/恢复、轴切换、两停着终局，并检查宽窄屏截图。
