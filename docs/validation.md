- `python3 -m unittest discover -s tests -v`：47 项通过（规则 25、启发式电脑 8、真实 HTTP 14）。规则与边界修正都有先失败后通过的行为验证。

- 浏览器教学中心白子：8 个邻点，唯一一气 `(1,1,1,2)`；在该点落黑后中心白子提走，悔棋完整恢复。
- 全部 12 种切片内有序双轴组合：81 个四维坐标均唯一且不丢失；交换显示轴后唯一一气保持同一坐标。
